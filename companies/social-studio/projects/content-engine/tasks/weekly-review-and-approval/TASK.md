1. Run the `quality-gate` rubric on every post in `in_review`. Post a scorecard on each and send back anything below the bar with actionable notes (max 2 rounds).
2. Once this week's posts have passed or been killed, build the weekly approval packet and submit it as one `request_board_approval` linking every post issue.
3. If some drafts are still in revision, send the packet with what's ready and add the rest as a short follow-up packet. Never hold the whole week for one post.
4. When the approval resolves, comment each post's verdict and slot and hand approved posts to the Social Media Manager.
